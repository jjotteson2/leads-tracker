# Chrome Extension

A Chrome extension I built while working through the Scrimba Fullstack Developer Path.

This project helped me practice JavaScript, working with the DOM, localStorage, and building a browser extension.

## Features

- Save links that you want to access later
- Save the URL of the current browser tab
- Store saved links using localStorage
- Delete saved links
- Keep saved links after closing and reopening the extension

## Built With

- HTML
- CSS
- JavaScript
- Chrome Extension APIs
- localStorage

## How to Install

Since this extension is not published on the Chrome Web Store, you can install it manually:

1. Download or clone this repository.
2. Open Google Chrome.
3. Go to `chrome://extensions`.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the project folder containing `manifest.json`.
7. The extension should now appear in your Chrome extensions.
